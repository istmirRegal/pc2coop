PC2Coop {version} – build live together in Planet Coaster 2

INSTALL
1. Extract this ZIP: right-click → "Extract All…".
2. In the extracted folder, double-click PC2Coop-Setup.exe and press "Install".
   If Windows says "Windows protected your PC": click "More info", then "Run anyway".
   Setup is just not signed.
3. If the mod loader ACSE is missing, Setup tells you and opens its download page.

Then in the game: main menu → "Multiplayer". Everyone needs the same version.
New version: start Setup → "Check for update".

SOMETHING NOT WORKING?
In the multiplayer window under "Settings", click "Create problem report". The file
lands on your desktop – send it to the developer (Discord or GitHub). Steam IDs and the
other players' names are replaced in it, chat is never in it.

WITH VORTEX OR BY HAND
Vortex: install this ZIP like any other mod and deploy. Then don't use Setup as well.
By hand: copy the folder Mod\PC2CoopProbe into <game folder>\Win64\ovldata.

More: https://github.com/istmirRegal/pc2coop · Licence: MIT (LICENSE.txt).
ACSE is not included (separate download, separate licence).
