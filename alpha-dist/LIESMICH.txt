PC2Coop {version} – Planet Coaster 2 live zusammen bauen
(English below)

INSTALLIEREN – ein Weg reicht
A) Mit Vortex (Nexus Mods): „Mod Manager Download“, danach „Deploy“. Fertig.
B) Mit Setup: PC2Coop-Setup.exe von https://github.com/istmirRegal/pc2coop/releases
   laden und doppelklicken, „Installieren“. Setup holt die Mod selbst, prüft sie und
   sucht später auch Updates. Fragt Windows „Der Computer wurde durch Windows
   geschützt“: „Weitere Informationen“ → „Trotzdem ausführen“.
C) Von Hand: den Ordner Mod\PC2CoopProbe aus dieser ZIP nach
   <Spielordner>\Win64\ovldata kopieren (Steam: Rechtsklick auf Planet Coaster 2 →
   Verwalten → Lokale Dateien durchsuchen). Danach liegt dort
   Win64\ovldata\PC2CoopProbe\Main.ovl.

PC2Coop braucht den Mod-Loader ACSE (Nexus Mods). Alle Mitspieler brauchen dieselbe Version.
Im Spiel: Hauptmenü → „Multiplayer“.

KLAPPT ETWAS NICHT?
Im Multiplayer-Fenster unter „Einstellungen“ auf „Problembericht erstellen“ klicken.
Die Datei landet auf dem Desktop – schick sie dem Entwickler (Discord oder GitHub).
Steam-IDs und Namen der Mitspieler sind darin ersetzt, Chat steht nie drin.

Mehr: https://github.com/istmirRegal/pc2coop · Lizenz: MIT (LICENSE.txt).
ACSE ist nicht enthalten (eigener Download, eigene Lizenz).


PC2Coop {version} – build live together in Planet Coaster 2

INSTALL – one way is enough
A) With Vortex (Nexus Mods): "Mod Manager Download", then "Deploy". Done.
B) With Setup: get PC2Coop-Setup.exe from https://github.com/istmirRegal/pc2coop/releases,
   double-click it, press "Install". Setup fetches the mod itself, checks it and later
   looks for updates. If Windows says "Windows protected your PC": "More info" →
   "Run anyway".
C) By hand: copy the folder Mod\PC2CoopProbe from this ZIP into
   <game folder>\Win64\ovldata. Then Win64\ovldata\PC2CoopProbe\Main.ovl is there.

PC2Coop needs the mod loader ACSE (Nexus Mods). Everyone needs the same version.
In the game: main menu → "Multiplayer".

SOMETHING NOT WORKING?
In the multiplayer window under "Settings", click "Create problem report". The file
lands on your desktop – send it to the developer (Discord or GitHub). Steam IDs and the
other players' names are replaced in it, chat is never in it.

More: https://github.com/istmirRegal/pc2coop · Licence: MIT (LICENSE.txt).
ACSE is not included (separate download, separate licence).
